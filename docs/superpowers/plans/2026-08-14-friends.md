**Architecture:** Add `Sim.friends: FriendRoster` keyed by durable character id (same pattern as `Mailbox` / `GuildRoster`). **Tech Stack:** Rust 2021 workspace crates (`woc-protocol`, `woc-sim`, `woc-persist`, `woc-server`, `woc-client`). No new crates. No Bevy inside sim.

### Task 1: Friend types, name resolve, add

**Files:**
- Create: `crates/woc-sim/src/social/friends.rs`
- Modify: `crates/woc-sim/src/social/mod.rs`

**Interfaces:**
- Consumes: `World`, `ClassKit`, `Identity`, `Health`, `Durable`, `Mailbox::mailbox_key`, `CharacterDirectory`
- Produces: `FriendEntry`, `SocialBook`, `FriendRoster`, `SocialEffect`, `FriendRoster::add`

Constants (spec §5.1): `MAX_FRIENDS = 50`, `MAX_IGNORE = 50`, `WHISPER_MAX = 200`.

Name resolve (spec §5.1):

1. Trim the typed name.
2. `CharacterDirectory::lookup` (case-insensitive) → durable key if present.
3. Else scan `World` `ClassKit` ids for exact `Identity.name` match.
4. Directory miss **and** not currently in world → `None` → `"No player named '{name}'."`
5. Owner key: `FriendRoster::owner_key(world, player_id)` = `Mailbox::mailbox_key`.

When the target is currently in the world with `ClassKit`, fill `name` / `class_id` / `level` from `Identity` + `ClassKit` + `Health`. When offline (directory hit, no live entity): `name` = trimmed typed name; `class_id` = last projection already stored on **any** book for that durable, else `""`; `level` = last projection, else `1`.

```rust
//! Persistent friend / ignore books (durable character id).

use std::collections::HashMap;

use crate::ecs::components::{ClassKit, Health, Identity};
use crate::ecs::World;
use crate::mail::{CharacterDirectory, Mailbox};
use woc_protocol::EntityId;

pub const MAX_FRIENDS: usize = 50;
pub const MAX_IGNORE: usize = 50;
pub const WHISPER_MAX: usize = 200;

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct FriendEntry {
    pub durable_id: String,
    pub name: String,
    pub class_id: String,
    pub level: u32,
}

#[derive(Debug, Clone, PartialEq, Eq, Default)]
pub struct SocialBook {
    pub owner_durable: String,
    pub friends: Vec<FriendEntry>,
    pub ignored: Vec<FriendEntry>,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum SocialEffect {
    Notice { to: EntityId, message: String },
    Error { to: EntityId, message: String },
    Chat {
        to: EntityId,
        channel: String,
        from: String,
        text: String,
    },
}

#[derive(Debug, Clone)]
pub enum SocialDelivery {
    To {
        player: EntityId,
        msg: woc_protocol::WsServerMsg,
    },
}

#[derive(Debug, Default, Clone)]
pub struct FriendRoster {
    books: HashMap<String, SocialBook>,
}
```

Whisper is **not** wired through `handle_chat`. Signature:

```rust
pub fn whisper(
    &self,
    from: EntityId,
    name: &str,
    text: &str,
    world: &World,
    directory: &CharacterDirectory,
    intents: &std::collections::HashMap<EntityId, woc_protocol::PlayerIntent>,
```

Rule order (spec §5.3) — stop at the first error:

1. `trim` text. Empty → `"Chat message is empty."`
2. `len() > WHISPER_MAX` → `"Chat message is too long."` (byte/char: use `text.chars().count()` if you already do that for guild chat; **match `handle_chat` / `GUILD_MESSAGE_MAX` length check exactly** — read `crates/woc-sim/src/social/chat.rs` and copy that predicate).
3. Resolve name. Fail → `"No player named '{name}'."`
4. Target durable == self → `"You cannot whisper yourself."`
5. You ignore them → `"You are ignoring {name}."`
6. They ignore you → `"{name} is ignoring you."`
7. Target has no intent slot (missing, parked, never spawned) → `"{name} is not online."`
8. Success: two `SocialEffect::Chat` channel `"whisper"`:
   - to target: `from` = speaker `Identity.name`, `text` = original trimmed
   - to self: `from` = `format!("To {name}")` where `{name}` is the resolved display name, `text` = same

Whisper does **not** require friendship. Whisper does **not** persist.
