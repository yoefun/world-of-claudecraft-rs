# Gear-more Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship rewrite `1.15.0` / `gear-more`: extra doll slots, Hunter dual-wield, off-hand enchant on the sheet, and instance loot quality.
